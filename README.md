# exercises

Exercises for "Quarto - authoring and publishing tools for collaborative scientific writing".

See https://quarto-rdmss-25.github.io/website/ for course website where exercises are used.

## Active exercises (used in the live session)

- `hello-penguins.qmd` - first contact with a Quarto document (Hello Quarto module)
- `markdown-syntax.qmd` - Markdown basics (Documents module)
- `citations.qmd` - citations and bibliographies (Documents module)
- `tables-figures.qmd` - figure and table cross-references (Documents module, used as homework)

Supporting files used by the active exercises:

- `references.bib` - bibliography used by `citations.qmd`
- `apa.csl` - APA citation style, optional stretch goal in `citations.qmd`

## Extras (self-study, not covered in the live session)

The `extras/` folder contains exercises that were taught in earlier versions of this course but were dropped to make space for citations in 2026. They still render and are useful for self-study:

- `extras/callout-boxes.qmd` - Quarto callout types and collapsible callouts
